# Baudsmith Studios

Baudsmith Studios is a collection of projects born from real problems — the kind you run into when you're deep in a homelab at 2am and the tool you need doesn't exist yet. The work here spans networking, Raspberry Pi, HAM radio, and the connective tissue between them.

These projects are opinionated — built around specific workflows, specific hardware, and a particular way of thinking about problems. They won't be for everyone, but when they fit, they fit well.

If something here fits your setup, use it. If it almost fits, fork it and make it yours. The code is open and the door is too.
